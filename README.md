# Jeremy's Portfolio Website (`jeremy7509.github.io`)

Personal developer portfolio for [@jeremy7509](https://github.com/jeremy7509), built with clean HTML5, modern CSS architecture (`@layer`, custom properties, dark mode theming), and vanilla JavaScript with live GitHub REST API integration.

## Live URL

Once pushed to the `main` branch of `jeremy7509/jeremy7509.github.io`, GitHub Pages automatically deploys the site to:

**https://jeremy7509.github.io**

## Structure

- `index.html` — Semantic HTML5 layout with Hero, About Me, Featured Projects, and Contact sections.
- `styles.css` — Modern Dark Mode stylesheet using CSS cascade layers (`@layer`), logical properties, and responsive grid layouts.
- `script.js` — Live GitHub API synchronization for `@jeremy7509` repositories and interactive project category filtering.
